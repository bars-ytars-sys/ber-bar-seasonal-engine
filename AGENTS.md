# Инструкция агенту (Codex и другие)

Проект — правки двух сайтов баз отдыха на Тильде:
**Берёзовая роща** (ecobr.ru, «БР») и **Барские поля** (barskie-polya.ru, «БП»).

**Начинать с [СТАТУС.md](СТАТУС.md)** — состояние сайтов, адреса, доступы,
замеры, грабли и очередь задач. Инструменты проверки — в `tools/`.

## Правила, заданные владельцем

- Отвечать **по-русски, сжато, сначала вывод**. Не перечислять варианты,
  которые не предлагаешь. Владелец торопит и раздражается на расплывчатые
  инструкции.
- Сайты правит **владелец руками в редакторе Тильды**. API Тильды — только
  на чтение, записи нет. Наша работа: готовый код в файле + точная инструкция,
  куда вставить (см. «Передача кода» в [СТАТУС.md](СТАТУС.md)).
- **Место блока называть по-человечески**: какая страница, какой по счёту
  блок сверху, между какими соседями, что в нём написано. Не голым `rec…`.
- **После каждой публикации проверять страницу целиком**, а не только свой
  блок — `node demo/check-live.mjs bp|eco`.
- **Сезонное оформление — три фазы**; фазы 2 и 3 не делать без просьбы.
- **Отчёты — PDF в корне проекта**, в git не идут (`*.pdf` в .gitignore).
  Короткие отчёты «что сделали за день» — текстом для Телеграма.
- Тон аудитов деловой, без «не проверено / гипотеза» у каждого абзаца.
- Вести `СТАТУС.md` по ходу работы, не в конце.

## Секреты

- `tools/.kie_key` — ключ kie.ai (генерация фото). **Не печатать, не коммитить,
  не вставлять в код.** Скрипты читают его из файла.
- `mcp/.tilda_keys` — не заведён; если появится — тоже не коммитить.
- Оба пути в `.gitignore`. Перед коммитом — `git status`, чтобы не утащить
  фото владельца из корня, PDF и `nul`.

## Git

Репозиторий `bars-ytars-sys/ber-bar-seasonal-engine`, ветка `main`.
Картинки для блоков раздаются GitHub Pages из `demo/assets/` — чтобы фото
появилось на сайте, его нужно закоммитить и запушить. Коммитить только по
просьбе владельца. Сообщения коммитов — по-русски, коротко.

## Окружение

Windows 11, Node.js, `playwright-core` (стоит, `npm install` при необходимости).
Браузер — установленный Chrome (`channel: 'chrome'`); в песочнице без Chrome —
путь к Chromium в переменной `PW_EXECUTABLE`. В пути проекта есть `&`
(`Desktop\Ber&Bar`) — в cmd пути брать в кавычки, файлы открывать через PowerShell.
