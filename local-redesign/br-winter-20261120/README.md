# Зимняя демка «Берёзовой рощи»

Отдельная сборка БР для просмотра. Берёт маршруты, навигацию, правки по таблице, подарочный сертификат и детские праздники из текущей ноябрьской демки. Собственный набор зимних фотографий хранится в этой папке.

Из корня репозитория:

```sh
python3 -B local-redesign/br-winter-20261120/build.py --root /tmp/br-winter-preview
python3 -m http.server 8188 --bind 127.0.0.1 --directory /tmp/br-winter-preview
```

[Открыть демо](http://127.0.0.1:8188/ber-bar-seasonal-engine/prevyu/lid/br-winter-20261120/).

- Зимние кадры первого экрана для телефона и компьютера и зимний вид из окна SPA.
- На главной обновлены внешние ракурсы в карточках домов, активности, открытые кадры в историях и низ страницы со спецпредложениями. Фотографии интерьеров и присланные фото детей сохранены.
- В каталоге 22 дома. Для 11 наружных обложек использованы сезонные версии соответствующих кадров. Остальные 11 обложек показывают исходные интерьеры. Полные галереи отдельных домов служат исходной справочной фотографией и могут содержать летние снимки.
- Обработка погоды сгенерирована на основе исходных кадров БР. Истории, вкладки, цены, ссылки и содержание программ берутся из базовой сборки.
- Анимация снега действует только на главной и учитывает настройку уменьшения движения. Исходный декоративный листопад исключён из зимней сборки.

Сборка сохраняет ограничения ноябрьского демо на отправку форм и бронирование. Публикация на Тильду не предусмотрена.
