# Чек-лист выката и план отката

---

## До публикации

**Бэкап.**
- [ ] `Страницы → ⋯ → Дублировать` для каждой изменяемой страницы.
      Название копии: `имя (бэкап ДД.ММ)`. Копию **не публиковать**.
- [ ] Если правится HEAD: скопировать весь текущий код HEAD в файл
      `backup/head-ДД.ММ-сайт.txt` и положить рядом с этим репозиторием.
      Откатить HEAD иначе нечем — Tilda не хранит его версии.

**Проверка данных.**
- [ ] `/special?debug=offers` — красная рамка пустая.
- [ ] У каждого оффера есть цена. Оффер без цены не публикуется.
- [ ] У каждого оффера `sale.to` — реальная дата, а не «через год».
- [ ] Промокод в карточке совпадает с промокодом, заведённым в Bnovo.
      Проверить в самом модуле: скидка применилась.
- [ ] Ни одного таймера без настоящего дедлайна.
- [ ] «Осталось N домов» — только если цифра сверена с Bnovo сегодня.

**Проверка ссылок.**
- [ ] Каждая кнопка «забронировать» открывает `/booking` с нужными датами.
- [ ] Промокод виден в фильтре модуля (`#ПРОМОКОД`).
- [ ] Плавающие даты (`mon`, `fri`, `+7`) превратились в конкретные.
- [ ] Ни одна кнопка оффера не ведёт на форму «связаться с менеджером»
      как на **основной** путь. Ручной канал — только второй кнопкой.

**Проверка дат.**
- [ ] `?date=` на день начала акции — блок появился.
- [ ] `?date=` на день после окончания — блок исчез.
- [ ] `?season=` следующего сезона — ничего не поехало.

**Мобильные — первым делом, не последним.**
- [ ] Телефон, реальный, не эмулятор: первый экран, `/special`, `/booking`.
- [ ] Анонс-полоса не наезжает на шапку и не съедает первый экран.
- [ ] Нижняя панель не перекрывает кнопки внутри модуля Bnovo.
- [ ] Карточки офферов читаются, кнопка попадает под палец.

**Скорость.**
- [ ] PageSpeed мобильный до и после — записать обе цифры.
      Просадка больше 5 пунктов — разбираться до публикации, не после.
- [ ] Новых внешних скриптов не добавилось. Все компоненты движка — без зависимостей.
- [ ] Новые картинки: не больше 250 КБ, ширина не больше 1600 px.

**Аналитика.**
- [ ] `?goals=debug` в консоли — цели пишутся при кликах.
- [ ] Цели заведены в Метрике и приняли хотя бы одно событие.
- [ ] Номера блоков, на которых висят цели, не изменились.

**SEO и соцсети.**
- [ ] Title и description страницы обновлены под сезон.
- [ ] OG-картинка обновлена — её видят в Telegram и ВК при репосте.
- [ ] Адрес страницы **не менялся**.

## Порядок публикации

1. Сначала **одна** страница, не весь сайт.
2. Открыть в режиме инкогнито с телефона.
3. 15 минут посмотреть Вебвизор: доходят ли до кнопки, не путаются ли.
4. Только потом публиковать остальное.

Не выкатывать в пятницу вечером и в первый день праздников.

## Откат

**Сломалась страница.**
`Страницы` → открыть бэкап-копию → `Настройки → Адрес страницы` → поставить
адрес сломанной, у сломанной адрес заменить на `broken-ДД-ММ` → опубликовать обе.
Время: 3 минуты. Адрес и позиции в поиске не страдают.

**Сломался сайт целиком после правки HEAD.**
`Настройки сайта → Ещё → HEAD` → вставить содержимое `backup/head-ДД.ММ-сайт.txt`
→ `Опубликовать все страницы`. Время: 5 минут.

**Пропало бронирование.**
Проверить блок `#rec3032928101` («Роща»): на месте ли `Bnovo_Widget.init` и UID
`9b88bc59-76a6-4230-8e86-85790f3854d4`. Проверить, что `/booking` открывается напрямую.
Если открывается — виноват не модуль, а сайт: откатывать HEAD.

**Каталог офферов пустой.**
Значит, сломан JSON. Открыть `/special?debug=offers` — там написано, что именно.
Быстрое лечение: удалить последний добавленный оффер целиком и опубликовать.

**Аварийное выключение всего движка.**
В HEAD, в самое начало блока 1, добавить строку `return;` сразу после
`(function () {`. Сайт вернётся к обычному виду Tilda, ничего не сломав.
