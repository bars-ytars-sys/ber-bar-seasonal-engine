# Движок сезонности для ecobr.ru и barskie-polya.ru

Система, которая позволяет менять облик сайта и офферы силами контент-менеджера,
без разработчика и без риска сломать бронирование.

Принцип: **сезонность — это подмена данных, а не переверстка.**

## Установка, 40 минут

**Шаг 0.** Скопировать текущий код HEAD обоих сайтов в файлы
`backup/head-ДД.ММ-ecobr.txt` и `backup/head-ДД.ММ-bp.txt`.
Tilda не хранит версии HEAD — откатить будет нечем.

**Шаг 1.** `Настройки сайта → Ещё → HTML-код для вставки внутрь HEAD`.
Вставить содержимое файлов **строго по порядку** 1 → 2 → 3 → 4 → 5.
Файлы 1–5 одинаковые для обоих сайтов: сайт определяется по домену.
Файлы 6 и 8 — только для `ecobr.ru`.

**Шаг 2.** Опубликовать все страницы. Проверить, что сайт выглядит как раньше:
на этом этапе ничего визуально меняться не должно — анонс-полоса выключена
(`enabled: false`), расписание пустое.

**Шаг 3.** На странице `/special` добавить блок `Другое → T123` и вставить
файл `7-katalog-offerov.html`. Открыть `/special?debug=offers` — рамка должна
быть без ошибок.

**Шаг 4.** Создать скрытую страницу `/tools`, поставить `noindex`, не добавлять
в меню, вставить туда блок T123 с файлом `9-generator-ssylok.html`.

**Шаг 5.** Прогнать чек-лист из `docs/chek-list-vykata.md`.

## Как проверить, что всё работает

| Адрес | Что должно быть |
|---|---|
| `сайт.ru/?season=newyear` | новогодняя палитра, внизу чёрная плашка предпросмотра |
| `сайт.ru/?date=2026-12-25` | страница такая, какой будет 25 декабря |
| `сайт.ru/?schedule=debug` | в консоли таблица: какой блок виден и почему |
| `сайт.ru/special?debug=offers` | список ошибок в офферах, пустой если всё верно |
| `сайт.ru/?goals=debug` | в консоли пишутся цели при кликах |

Все параметры безопасны: их видит только тот, кто их набрал.

## Ключевые факты, на которых всё держится

**1. `/booking` уже принимает параметры.**
Библиотека `booking_iframe.js` читает GET-параметры адресной строки и передаёт
их в модуль. Проверено на живом модуле. Работает без всякого кода:

```
https://ecobr.ru/booking?dfrom=2026-12-30&dto=2027-01-03&adults=2&promoCode=NY2027&scroll_to_rooms=1
```

Параметры: `dfrom`, `dto` (ГГГГ-ММ-ДД), `adults`, `children`, `promoCode`,
`onlyrooms`, `currency`, `lang`, `scroll_to_rooms`, `insidePopup`, `firstroom`,
`servicemode`, `disable_block_scrolls`, `utm_*`.

**2. Bnovo уже шлёт цели в ваши счётчики.**
В его скрипте прописан `ym(yaCounterIdAccount, 'reachGoal', …)`, где
`yaCounterIdAccount` — это `108978291` (Роща) и `109033653` (Барские поля).
События идут; их надо только завести целями в интерфейсе Метрики.
Список — в шапке файла `head/5-celi-metriki.html`.

**3. `ecobr.ru` покрашен шестью переменными Tilda.**
Объявить их в `:root` — перекрасится весь сайт.
`barskie-polya.ru` Цветовых стилей не использует — до миграции палитры
(задача Б2 в смете) сезон меняет там только компоненты движка.

## Правила, которые нельзя нарушать

- Не менять адреса существующих страниц.
- Не пересоздавать блоки, чьи номера стоят в расписании или в целях Метрики.
- Не трогать блок с виджетом Bnovo (`#rec3032928101` на «Роще»).
- Не ставить таймер без реального дедлайна.
- Каждое решение проверять вопросом: сможет ли это поменять человек без доступа
  к коду? Если нет — переделать.
