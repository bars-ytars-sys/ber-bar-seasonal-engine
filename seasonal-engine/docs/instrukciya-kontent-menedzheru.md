# Инструкция контент-менеджеру

Здесь всё, что можно менять без разработчика. Каждая операция — от 3 до 20 минут.
Если для задачи нужен разработчик — об этом сказано прямо.

**Общее правило перед любой правкой:** сделайте копию страницы.
`Страницы → ⋯ у нужной страницы → Дублировать` → у копии в названии поставьте
дату: `special (бэкап 15.11)`. Копия не публикуется и никому не видна.

---

## 1. Поменять акцию в каталоге спецпредложений

**Где:** сайт → страница `Спецпредложения` (`/special`) → блок с HTML-кодом
(подписан «Каталог офферов») → `Контент`.

Внутри — список офферов. Один оффер выглядит так:

```json
{
  "id": "budni-osen",
  "title": "Будни −20%",
  "lead": "Заезд понедельник–четверг. Тот же дом, та же баня, цена ниже.",
  "price": 11900,
  "oldPrice": 14900,
  "priceNote": "за дом в сутки",
  "badge": "hot",
  "tags": ["budni", "dvoim", "banya"],
  "includes": ["Завтрак на двоих", "Поздний выезд до 14:00"],
  "excludes": ["Банный чан — 4 500 ₽ за 3 часа"],
  "rules": "Минимум 2 ночи. Не суммируется с другими акциями.",
  "stay": { "from": "2026-09-01", "to": "2026-11-30" },
  "sale": { "from": "2026-09-01", "to": "2026-11-25" },
  "promo": "BUDNI20",
  "book": { "from": "mon", "to": "thu", "adults": 2 },
  "more": ""
}
```

Что означает каждая строка:

| Поле | Что это | Обязательно |
|---|---|---|
| `id` | короткий код оффера латиницей, без пробелов | да |
| `title` | название, 2–4 слова | да |
| `lead` | суть одной строкой | да |
| `price` | цена «от», только цифры, без пробелов и ₽ | **да** |
| `oldPrice` | старая цена, будет зачёркнута. Не пишите выдуманную | нет |
| `priceNote` | за что цена: «за дом в сутки», «пакет на двоих» | да |
| `badge` | метка: `hot`, `new`, `last` или `""` | нет |
| `tags` | фильтры: `dvoim`, `semya`, `kompaniey`, `budni`, `banya`, `spa`, `sertifikat`, `korporativ` | да |
| `includes` | что входит, списком | да |
| `excludes` | что оплачивается отдельно | нет |
| `rules` | ограничения одной фразой | да |
| `stay` | на какие даты **заезда** действует | да |
| `sale` | **срок жизни самой акции**. После `sale.to` карточка исчезнет сама | **да** |
| `promo` | промокод, подставится в модуль автоматически | нет |
| `book` | что подставить в модуль при клике по кнопке | да |
| `more` | адрес подробной страницы, если она есть | нет |

**Поле `book` — самое важное.** Оно решает, куда попадёт гость.

- `"from": "2026-12-30"` — конкретная дата.
- `"from": "mon"` — ближайший понедельник. Считается в момент клика,
  поэтому оффер «будни» не протухает никогда.
  Можно: `mon`, `tue`, `wed`, `thu`, `fri`, `sat`, `sun`.
- `"from": "+7"` — через 7 дней от сегодня.

**Дата выезда (`to`) считается от даты заезда, а не от сегодня.**
Это важно: `{"from":"mon","to":"thu"}` — это понедельник и четверг одной недели,
а не ближайший четверг, который может оказаться раньше понедельника.
Можно писать и ночами: `{"from":"fri","to":"+2"}` — пятница плюс две ночи.

Не уверены, что написать — откройте `/tools` (генератор ссылок), соберите
ссылку мышкой и посмотрите, какие получились параметры.

**Порядок работы:**
1. Скопируйте существующий оффер целиком, от `{` до `}`.
2. Вставьте ниже, через запятую.
3. Поменяйте поля.
4. Сохраните блок, опубликуйте страницу.
5. **Обязательно** откройте `сайт.ru/special?debug=offers` — вверху появится
   красная рамка со списком ошибок. Пусто — всё в порядке.

**Частые ошибки:**
- Забыта запятая между офферами. Проверка её покажет.
- Цена написана как `"11 900"` или `"11900 ₽"`. Правильно: `11900`, без кавычек.
- Дата написана как `15.11.2026`. Правильно: `"2026-11-15"`.
- Кавычки скопированы из Word («ёлочки»). Нужны прямые: `"`.

**Убрать оффер прямо сейчас, не удаляя:** поставьте `sale.to` во вчерашний день.

## 2. Включить или поменять анонс-полосу под шапкой

Полоса одна на весь сайт: меняете в одном месте — меняется везде.

**Где:** `Настройки сайта → Ещё → HTML-код для вставки внутрь HEAD` →
найдите комментарий `БЛОК 4 · АНОНС-ПОЛОСА` → внутри объект `ANNOUNCE`.

```js
eco: {
  enabled: true,
  id:    'eco-2026-11-budni',
  text:  'Будни ноября: −20% при заезде с понедельника по четверг. Промокод BUDNI20',
  cta:   'Выбрать даты',
  href:  '/booking?dfrom=mon&dto=thu&adults=2&promoCode=BUDNI20',
  from:  '2026-11-01',
  until: '2026-11-30'
}
```

- `enabled: true` — включить, `false` — выключить.
- **`id` меняйте при каждой новой акции.** Гость, закрывший прошлую полосу,
  иначе не увидит новую в течение недели.
- `href` — лучше сразу в бронирование. Ссылку соберите на `/tools`.
- После `until` полоса пропадает сама.

Текст — одна строка: что даём, кому, до когда. «Успейте забронировать» — не текст.

## 3. Показать или спрятать блок по датам

Чтобы новогодний баннер сам появился 1 декабря и сам исчез 10 января.

**Шаг 1.** Соберите блок в Tilda как обычно и опубликуйте.
**Шаг 2.** Наведите на блок в редакторе — слева написан его номер, вида `#rec1234567890`.
Скопируйте.
**Шаг 3.** `Настройки сайта → Ещё → HEAD` → блок `БЛОК 2 · РАСПИСАНИЕ` →
добавьте строку в `SCHEDULE`:

```js
{ rec:'rec1234567890', from:'2026-12-01', to:'2027-01-10', note:'НГ-баннер' },
```

Варианты:
- только даты — `from` / `to`;
- только сезон — `season:'winter'` (или `season:'autumn,newyear'`);
- наоборот, **спрятать** в эти даты — добавьте `mode:'hide'`.

**Проверка:** откройте `сайт.ru/?date=2026-12-25` — увидите страницу такой,
какой она будет 25 декабря. И `?date=2027-02-01` — убедитесь, что НГ-блоков нет.

## 4. Переключить сезон

Сезон меняется сам по календарю: НГ с 15 ноября, зима с 11 января, весна с 8 марта,
лето с 9 мая, осень с 1 сентября.

**Посмотреть заранее:** `сайт.ru/?season=newyear`.
Сезоны: `newyear`, `winter`, `spring`, `summer`, `autumn`.
Внизу появится чёрная плашка «предпросмотр» — это видно только вам, до закрытия вкладки.

**Сдвинуть дату начала сезона:** `Настройки сайта → Ещё → HEAD` → блок 1 →
таблица `SEASONS`, формат `ММ-ДД`.

**Поменять цвета сезона** — правка CSS, зовите разработчика.
Исключение: если нужен просто другой оттенок из уже готовых — скажите,
какой сезон на какой поменять, это правка одной строки.

## 5. Собрать ссылку в бронирование для рекламы или рассылки

Откройте `/tools` — это служебная страница, её нет в меню.
Выберите базу, даты, число гостей, промокод и UTM-метки → «Скопировать».

Готовую ссылку можно ставить куда угодно: в кнопку Tilda, в пост, в рассылку,
в объявление. Даты и промокод подставятся в модуль автоматически.

Проверьте ссылку кнопкой «Проверить ссылку» — модуль должен открыться
с нужными датами, а промокод — появиться в фильтре.

## 6. Чего делать нельзя

- **Не меняйте адреса существующих страниц** (`/special`, `/doma`, `/booking`).
  Развалится поисковая выдача и часть рекламы.
- **Не удаляйте и не пересоздавайте блоки, номера которых стоят в расписании
  или в целях Метрики.** Пересозданный блок получает новый номер, и статистика
  обнуляется. Нужно изменить блок — редактируйте существующий.
- **Не трогайте блок с виджетом Bnovo** (`#rec3032928101` на «Роще»).
  Там UID модуля; ошибка — и бронирование пропадает со всего сайта.
- **Не ставьте таймер на акцию без реального дедлайна.** Таймер, который
  каждый день начинается заново, гости замечают — и перестают верить остальному.
- **Не пишите «осталось 2 дома», если не посмотрели в Bnovo.**
