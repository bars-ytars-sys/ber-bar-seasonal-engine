# Осень 2026 — что и куда вставлять

Два сайта, по три файла на каждый плюс картинки. Порядок важен: сначала
картинки, потом код, потом ручные правки в редакторе.

Весь код проверен на копиях живых сайтов: раскладка листьев замерена —
ни один лист не ложится на кнопки и текст ни на 1600px, ни на 390px.

---

## Берёзовая роща — ecobr.ru

### 1. Картинки

`Берёзовая-роща/картинки/` → **Настройки сайта → Файлы**

| файл | куда |
|---|---|
| `card-banya.webp` | карточка «Банный отдых с самоваром» |
| `card-chan.webp` | карточка «Ароматная осень» |
| `card-kanikuly.webp` | карточка «Осенние каникулы» |

Скопируйте адреса — они понадобятся в шаге 3.

### 2. Код

| файл | куда |
|---|---|
| `1-HEAD.html` | Настройки сайта → Ещё → **HTML-код в HEAD** |
| `2-BODY.html` | Настройки сайта → Ещё → **HTML-код перед `</body>`** |

Дальше — «Опубликовать все страницы».

Номера блоков внутри уже проставлены: ветки-разделители, появление,
букеты в углах, свисающая рябина, колосья. Гирлянда выключена — на первом
экране она лишняя.

Листопад живёт на первом экране и растворяется к полутора экранам
прокрутки. Холст и боковые полосы закреплены за окном браузера, без этого
они ехали бы за гостем через весь сайт и мешали читать.

### 3. Блок «Тёплая осень»

**Библиотека → Другое → T123 (HTML-код)** → вставить `3-BLOK-tyoplaya-osen.html`
целиком.

Место: на главной, **сразу под блоком `rec1694735441`** — тот, где сейчас
заголовок «Ради нас берут выходной!».

В коде найдите три строки `ФОТО_card-…webp` и подставьте вместо них
адреса из шага 1.

### 4. Правки мышкой в редакторе

Блок `rec1694735441` — это Zero Block, правится в редакторе:

- заголовок → **«Тёплая осень»**
- подзаголовок → **«Ради нас берут выходной!»** (было про Яндекс)
- блок высокий и почти пустой: **потяните низ вверх**, примерно
  с 261 до 155 по высоте, и поднимите оба текста — иначе между заголовком
  и карточками остаётся дыра почти в экран

### 2. Код

| файл | куда |
|---|---|
| `1-HEAD.html` | Настройки сайта → Ещё → **HTML-код в HEAD** |
| `2-BODY.html` | Настройки сайта → Ещё → **HTML-код перед `</body>`** |

**Перед вставкой** откройте `2-BODY.html` и впишите адреса загруженных
листьев: `leaf-*.png` в `leafImages`, `maple-*.png` в `decorImages`.
Без картинок набор не покажет ничего — он весь построен на них.

Раскладка:

|---|---|
| первый экран | только листопад |
| `rec1534422731` перед картой | цепочка после блока |
| `rec1216602591` заголовок программ | дуга сверху |
| `rec1185039476` «Дома» | россыпь, нижний левый угол |
| `rec1185039536` заголовок отзывов | дуга сверху |
| `rec2709575101` заголовок внизу | россыпь, верхний правый угол |

Листья по низу экрана выключены: справа внизу висит чат-виджет.
На телефоне россыпи в углах отключены — блоки там короткие, и листья
неизбежно ложились на текст.

### 3. Блок осенних акций

**Библиотека → Другое → T123 (HTML-код)** → вставить
`3-BLOK-osennie-akcii.html` целиком.

Место: на главной, **вместо блока `rec1655343021`** «Отдых сейчас —
оплата потом!». Сам блок не удаляйте — снимите галочку показа, после
сезона вернёте.

Подставьте адреса фотографий вместо `ФОТО_bp-…webp`.

### 4. Правки мышкой в редакторе

**Карточка «Продлеваем лето»** в ряду акций — акция закончилась 10.09,
удалите или скройте карточку. Ряд выложен флексом, соседние сдвинутся
сами, дыры не останется.

**Всплывающее окно `rec2461410871`** — было «Продлеваем лето», делаем
«Вкусную осень»:

- заголовок → **Вкусная осень**
- текст → **Завтраки в будни — в подарок**, ниже промокод **ОСЕНЬ2026**
  и строка **Акции не суммируются**
- фотография → `bp-popup.webp`
- кнопка → **«Подробнее об акции»**, ссылка на якорь блока акций

**Карточка «Дорога к отдыху должна быть лёгкой!»** — выделите слова
**«заправка в удобном месте»** акцентным цветом `#EE995D`. Сейчас суть
предложения тонет в общем тексте.

## Что осталось за кадром

**Венки и куча листьев.** В схеме были раскладки `wreaths` и `piles`, но
в скачанном наборе `BP2BODY.html` их нет — там только `corners`,
`topStrips`, `bottomStrips`, `dividersAfter`, `falling`, `ground`.
Заголовки «Дома» и «Отзывы» получили дуги вместо венков, подвал остался
без кучи. Пришлёте новую версию набора — переложу как задумано.

**Часть 1 набора Барских полей.** В загрузках был только `BP2BODY.html`.
Файл `1-HEAD.html` написан мной под этот скрипт: он задаёт только
позиционирование, без которого холст листопада нулевого размера.
Придёт настоящая часть 1 — замените.

**Кнопки бронирования** в обоих блоках ведут прямо в модуль Bnovo
с подставленными датами и промокодом. Параметры проверены на живом
модуле: `dfrom`, `dto`, `adults`, `children`, `promoCode`, `scroll_to_rooms`.
