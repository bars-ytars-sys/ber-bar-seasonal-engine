# Заголовки и описания страниц — готовые тексты

11.09.2026. Всё правится руками в редакторе: открыть ссылку → вверху
«Настройки» → нужная вкладка → вставить → «Сохранить» → опубликовать страницу.

- **Заголовок** и **Описание** — вкладка «Основные» (это title и description
  для поиска).
- **Соцсети** — вкладка для превью в мессенджерах: заголовок, описание, картинка.

Сначала — ошибки (раздел 1), остальное по желанию.
