# Движок сезонности для Tilda

Система, которая позволяет менять облик сайта и офферы силами контент-менеджера,
без разработчика и без риска сломать бронирование. Сделана под две загородные базы
одного владельца — **ЭкоБаза «Берёзовая роща»** (ecobr.ru) и
**База отдыха «Барские поля»** (barskie-polya.ru), обе на Tilda с модулем Bnovo.

Принцип: **сезонность — это подмена данных, а не переверстка.**

## Что посмотреть

| | |
|---|---|
| **Демо-стенд** | [`index.html`](index.html) — переключайте сезон и дату, смотрите, как меняются палитра, анонс-полоса, состав блоков и живые офферы |
| **Playbook** | [`playbook.html`](playbook.html) — аудит, архитектура, календарь релизов, смета |
| **Код компонентов** | [`seasonal-engine/`](seasonal-engine/) — то, что вставляется в Tilda |
| **Инструкция контент-менеджеру** | [`seasonal-engine/docs/instrukciya-kontent-menedzheru.md`](seasonal-engine/docs/instrukciya-kontent-menedzheru.md) |

Стенд не макет: на нём исполняется тот же код, что идёт в Tilda.
Кнопки «Забронировать» ведут на настоящий модуль Bnovo с подставленными датами.

## Устройство

```
seasonal-engine/
├── head/                        вставляется в HEAD, порядок важен
│   ├── 1-tema-sezona.html       ядро, определение сезона, палитра
│   ├── 2-raspisanie-blokov.html показ и скрытие блоков по датам
│   ├── 3-bnovo-deeplink.html    прямой переход в бронирование, цели
│   ├── 4-anons-polosa.html      сквозная полоса под шапкой
│   ├── 5-celi-metriki.html      цели сайта и список целей Bnovo
│   └── 6-vk-pixel-ecobr.html    пиксель ВК
├── blocks/                      вставляется блоком T123 на страницу
│   ├── 7-katalog-offerov.html   каталог спецпредложений → /special
│   ├── 8-mobile-sticky-cta.html нижняя панель на мобильном
│   └── 9-generator-ssylok.html  генератор ссылок → служебная /tools
└── docs/                        аудит, инструкции, календарь, чек-листы, смета
```

Ни одной внешней зависимости: компоненты ничего не грузят и не замедляют сайт.

## Разработка

```bash
node test/engine.test.mjs   # 34 проверки логики движка
node demo/build.mjs         # пересобрать index.html и playbook.html
```

Тесты гоняют настоящий код компонентов: скрипты вырезаются из html-файлов
и исполняются в минимальной заглушке браузера. Поменяли компонент — тесты это увидят.

Стенд собирается из тех же файлов. Единственное отличие от боевой вставки —
сборщик подставляет три демо-строки в таблицу расписания и расширяет окно дат
анонс-полосы, чтобы её было видно на любую выбранную дату. Что именно
патчится — видно в [`demo/build.mjs`](demo/build.mjs).

## Что проверено на живых сайтах

Всё в аудите снято с исходников страниц и виджета Bnovo, а не из документации.

**Страница `/booking` уже принимает параметры из адресной строки.** Библиотека
`booking_iframe.js` читает GET-параметры и передаёт их в модуль:

```
https://ecobr.ru/booking?dfrom=2026-12-30&dto=2027-01-03&adults=2&promoCode=NY2027&scroll_to_rooms=1
```

Работают `dfrom`, `dto`, `adults`, `children`, `promoCode`, `onlyrooms`,
`currency`, `lang`, `scroll_to_rooms`, `insidePopup`, `firstroom`, `servicemode`,
`disable_block_scrolls`, `utm_*`. Даты в формате `ГГГГ-ММ-ДД`.

**Модуль Bnovo уже отправляет цели в счётчики Метрики** — их осталось только
завести в интерфейсе. Список идентификаторов воронки в
[`head/5-celi-metriki.html`](seasonal-engine/head/5-celi-metriki.html).

**ecobr.ru покрашен шестью переменными Tilda** — объявить их в `:root` значит
перекрасить весь сайт. У barskie-polya.ru Цветовых стилей нет; до миграции
палитры сезон меняет там только компоненты движка.
